# DEBT-003. Обход stage-gate через Bash не зафиксирован как граница

## Суть
У prod-guard граница честно задокументирована («покрывает только Bash»). У
stage-gate симметричная дыра: `echo > file`, `sed -i`, `tee` через Bash пишут код на любой
стадии — нигде не отмечено. Закрывать эвристиками по Bash-командам не стоит (хрупко).

## Рекомендация
Задокументировать границу в разделе «Enforcement-слой» `protocol.md` —
по тому же стандарту честности, что у prod-guard.

## Резолюция
Отложено грумингом `grooming-sdx-2-0-20260831` в ожидании волны 2 (`PROC-012`/`PROC-013`):
обход `stage-gate` через `Bash` перестаёт существовать вместе с самим `stage-gate`. Чинить запись отдельной сессией — работа, которая будет выброшена сносом.

Отсрочка защищена тем, что линия 1.7.0 заморожена, тегирована и содержит дефект как есть:
у пользователей 1.7.0 поведение не меняется, а на 2.0 запись либо исчезает вместе с предметом,
либо возвращается в `open`, если снос будет отклонён или сокращён.
