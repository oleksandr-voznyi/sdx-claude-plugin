# DEBT-044. Идентичность вендорённой копии проверяется только в чекауте, не в установленной копии плагина

## Суть
Сторож `test-mo-inventory.sh` хеширует `sdx/mo/` рабочего дерева. Хук исполняется из установленной копии
(`~/.claude/plugins/cache/sdx/...`), и установщик не обязан сохранять файлы байт в байт (прецедент `BUG-008`:
режимы файлов). Подмена или порча вендорённого файла в установленной копии не обнаруживается ничем.

## Рекомендация
В `mo-session.sh` (или self-test, `DEBT-043`) при наличии `.mesh/endpoint.yaml` сверять `sha256` файлов
`sdx/mo/` установленной копии с `SIMKIT_SHA256` той же копии и предупреждать одной строкой при расхождении.
Это не защита от злонамеренной подмены (хеш-файл лежит рядом), а детектор порчи при установке.
