# DEBT-046. В корне репозитория лежит посторонний пустой tracked-файл `false`

## Суть
Файл `/false` (0 байт) попал в коммит `a4c67a6` сессии `refactor-tracks-collapse-20260901` — по виду, результат
редиректа `> false` вместо `|| false`. Не задевает ничего, но это артефакт в корне плагина, который уезжает
к каждому пользователю при установке.

## Рекомендация
`git rm false` отдельной мелкой сессией (или попутно следующей); проверить, нет ли других пустых файлов
в корне (`find . -maxdepth 1 -type f -empty`).
