# DEBT-049. Границы покрытия FEAT-016: эвристические инварианты прозы `[12b]`, резервные ветки `mo-session` без теста, `[8h]`/`[8h2]`/`[8h4]` без своего мутанта

## Суть
Семь кругов fresh-eyes `feat-016-mo-mandate-20261028` назвали три границы покрытия, сознательно оставленные: (а) отрицательные
инварианты прозы `test-mo-prose.sh [12b]` (нет устаревших формулировок о мосте/оффере) — регулярные выражения с окном до `;`/`.`,
красные стороны подобраны под шаблон, применяются к подмножеству носителей; (б) резервные ветки `mo-session.sh` при недоступной
`lib/mandate.sh` не покрыты; (в) `[8h]` краснеет на мутанте `TRANSLATE` вместе с `[8a]`, `[8h2]`/`[8h4]` — характеризационные
проверки эталона без собственного мутанта. Класс `DEBT-040`/`DEBT-041`: проверки, которые доказывают меньше, чем кажутся.

## Рекомендация
(а) заменить регулярные выражения структурным инвариантом (единый источник формулировки моста в протоколе, остальные носители —
ссылкой); (б) сценарий с подменённой `CLAUDE_PLUGIN_ROOT` без `lib/`; (в) мутант обёртки, различающий `DENY [MO-scope]` от
`DENY [MO-exec-paths]`.
