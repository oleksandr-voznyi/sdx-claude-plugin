# FEAT-010. Асимметричная выдача полномочий

## Суть
Фиксация двух фактов отвечает на вопрос «что записываем», но не «что читает выдача полномочий».
Развилка разбора: `declared` честнее по ответственности, `observed` не сгниёт — но именно
`observed` даёт агенту способ повышать себе полномочия, что противоречит инварианту `PROC-020`.

## Рекомендация
Функция асимметрична по направлению:

- **Вниз** — любой факт действует немедленно и односторонне. Инцидент, эскалация, провал
  self-test (`FEAT-014`) → уровень падает. Понижение автономии не требует санкции человека.
- **Вверх** — `effective = min(declared, observed)`. Доказательства выше декларации не расширяют
  полномочия сами, а порождают предложение: «область X набрала признаки уровня 3 — подтвердить?».
  Одно нажатие, но нажатие человека.

Инвариант «агент не расширяет собственные полномочия» сохранён; доказательства при этом делают
настоящую работу — не дают декларации врать.

## Зависимости и порядок
После `FEAT-009`. Читается модулем полномочий `FEAT-006` перед каждым решением класса риска.
Диагностика расхождения — `IDEA-009`.
