# IDEA-009. Калибровка постановщика по расхождению `declared` / `observed`

## Суть
Раз оба факта хранятся честно, интересна не каждая величина, а их разница:

| | `observed` низкий | `observed` высокий |
|---|---|---|
| `declared` высокий | **непроверенный оптимизм** — опасный квадрант | норма, автономия заслужена |
| `declared` низкий | терра инкогнита, всё честно | **невостребованная автономия** — дешёвый выигрыш |

Верхний левый квадрант — целевой режим отказа brownfield-проектов. Раньше он был невидим; при
двойной фиксации становится списком, предъявляемым до прогона, а не после инцидента.

Отдельно ценна фиксация выведенного состояния **после** декларации: она даёт калибровку
конкретного человека. Декларация опередила факт и подтвердилась → порог подтверждения по этому
классу деклараций можно снижать. Опередила и случился инцидент → это сигнал не по одной области,
а по **классу**: «в областях с внешними эффектами оценки этого постановщика оптимистичны», и
понижать надо порог доверия к классу, а не уровень одной области.

## Рекомендация
Отчёт по квадрантам в `/sdx:status` или отдельной командой. Пороги доверия по классам деклараций —
после накопления статистики, не сразу.

## Резолюция
Не начинать до накопления данных: механизм требует истории, которой ещё нет.
