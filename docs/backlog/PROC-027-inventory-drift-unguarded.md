# PROC-027. У поверхностей, пересказывающих состав системы, нет сторожа

## Суть
Три поставки подряд оставляли за собой одно и то же расхождение — документ, перечисляющий состав
системы своими словами, отставал от фактического состава, и ни один тест этого не ловил:

- `README.md`/`README.en.md` заявляли «15 команд» поимённым списком, когда команд стало 16
  (поставка `PROC-019`, `/sdx:resume`);
- манифест плагина не называл новую возможность (поставка `FEAT-014`, self-test);
- `preflight.sh` не значился там, где перечислялись хуки (ранее).

Свойство, общее для всех трёх: расхождение **не находится грепом по предметному термину**.
Перечень содержит голые имена и описывает систему прозой, поэтому `grep resume` по репозиторию
не подсказывает, что в таблице README не хватает строки. Автор правки не видит поверхность,
которую задел, потому что связь между кодом и её описанием нигде не выражена.

Прецедент решения в репозитории уже есть и работает: `sdx/hooks/test-init-patterns.sh` — статический
сторож, сверяющий `.gitignore` репозитория с каноническим списком `/sdx:init`. Он был написан
против ровно этого класса и сразу поймал второе расхождение, о котором никто не знал.

## Рекомендация
Завести такой же статический сторож для перечней состава — сьют, сверяющий с фактом:
1. число и имена файлов `commands/*.md` против таблицы в `README.md` и `README.en.md`
   (обе локали, расхождение между ними — тоже находка: они уже расходились раньше);
2. состав `agents/*.md` против перечня ролей в `CLAUDE.md` §2;
3. состав `sdx/hooks/*.sh`, проводных в `hooks/hooks.json`, против описания слоя в
   `sdx/protocol.md` и `README`.

Красная сторона обязательна и здесь дёшева: мутант-копия README без одной строки перечня должна
ронять сценарий. Без неё сторож повторит судьбу самих перечней.

## Границы
Сторож ловит расхождение СОСТАВА, а не устаревшее ОПИСАНИЕ: строка «resume — возобновление
прогона» может остаться в таблице и после того, как команда изменит смысл. Это принципиальный
предел статической сверки имён, его стоит назвать в комментарии сьюта, а не делать вид, что
перечень теперь охраняем целиком.
