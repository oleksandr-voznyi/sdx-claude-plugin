# Постоянное хранилище отчётов аудита (`/sdx:audit`)

Сюда команда `/sdx:audit` пишет отчёт каждого прогона под именем `audit-<YYYY-MM-DD>[-N].md`
(ADR-019). Хранение накопительное: прогоны не перезаписывают друг друга, отчёт после записи
иммутабелен — сравнение прогонов во времени и есть смысл этого каталога.

В отличие от `docs/history/{retro,postmortem,intake}/`, здесь лежат **не документы разбора**:
тип сессии `audit` постоянного документа не производит (второй тип трека `doc` без него, наравне
с `grooming`) — выходом его триажа являются записи `docs/backlog/`, а предметом разбора служат
сами отчёты из этого каталога.

Этот файл — **заглушка для версионирования каталога, а не индекс прогонов**: он не перечисляет
отчёты и не обязан обновляться при их появлении. Индекс здесь сознательно не заводится (тот же
класс, что `DEBT-020`).
